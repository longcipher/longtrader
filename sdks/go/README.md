# longtrader-sdk (Go)

Tier-2 thin wrapper over the generated longtrader Connect stubs. Hand-written
code stays minimal — session handling plus overflow policies — while all
trading semantics live in the contract (`proto/`, buf-managed).

## Canonical layout (design doc §6.8)

| Canonical dir | This SDK |
|---|---|
| `contract/` | `gen/` — generated by `just sdk-generate` (`paths=source_relative`), never hand-edited |
| `session/` | `session/` — `Session` attach / keep-alive / reconcile / kill-switch |
| `ports/` | `ports/` — `TradingPort`, `MarketPort`, `OverflowPolicy` |
| `adapters/` | thin by design: Connect-over-http inside `session/`; mock adapter planned |
| `strategies/` | `strategies/` — the same grid ships in every language |
| `examples/` | `examples/` |

Concept names match the Python/TypeScript/Rust wrappers 1:1 (`Session`,
`TradingPort`, `MarketPort`, `sync_state()`, `OverflowPolicy`).

## Proto namespaces

| Service | Proto package | Stubs | Notes |
|---|---|---|---|
| market | `longtrader.market.v1` | `gen/longtrader/market/v1/` | candles, ticker, order book |
| trading | `longtrader.trading.v1` | `gen/longtrader/trading/v1/` | orders, positions, account |
| worker | `longtrader.worker.v1` | `gen/longtrader/worker/v1/` | session lifecycle |
| data | `longtrader.data.v1` | `gen/longtrader/data/v1/` | dataset download/list/validate/delete, streaming `DownloadProgress` |
| backtest | `longtrader.backtest.v1` | `gen/longtrader/backtest/v1/` | `Start`/`Cancel`/`ListRuns`/`GetReport`/`StartReplaySession` |

Generated stubs are produced by `just sdk-generate` into `gen/` (never hand-edit).

## Quickstart

```bash
just sdk-generate          # generates stubs into gen/ via buf generate
go run ./examples/grid_strategy --help
```

Minimal use:

```go
s, _ := session.Attach("http://127.0.0.1:8080", "YOUR_TERMINAL_TOKEN")
s.StartHeartbeat()
snap, _ := s.SyncState() // gate to ACTIVE; pre-ACTIVE orders are rejected
fmt.Println(s.SessionID(), s.State(), snap.SnapshotSequence)
s.Close()
```

## Wire notes

- Unary calls: `POST {base}/longtrader.worker.v1.WorkerSessionService/{Method}`,
  `Content-Type: application/proto`; errors arrive as non-200 JSON bodies
  surfaced as `ConnectError`.
- Server-streaming uses `application/connect+proto` with 5-byte envelopes
  (1 flag byte + u32 big-endian length; flag `0x02` = end-of-stream JSON).
  See `docs/bare-protocol-guide.md` sections 4–5 and `envelope` helpers in Rust.
- Auth is the existing terminal API token passed to `AttachSession`.
- `OverflowPolicy` governs event-queue behavior under slow consumers
  (`DropOldest` preserves newest, `Coalesce` last-writer-wins, `Block`
  applies backpressure); sequence gaps require snapshot resync/reconcile.

## Local regeneration

Requires `buf` CLI. From repo root:

```bash
buf generate --template proto/buf.gen.yaml
# or
just sdk-generate    # cd proto && buf generate
# For fully local regeneration without remote plugins:
bash scripts/gen-proto.sh
```

`proto/buf.gen.yaml` contains the Go plugin entry:

```yaml
- remote: buf.build/protocolbuffers/go:v1.36.10
  out: ../sdks/go/gen
  opt:
    - paths=source_relative
```

Output is `sdks/go/gen` (quarantined contract, never hand-edited).
