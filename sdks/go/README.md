# longtrader-sdk (Go)

> **Beta.** Hand-written `Session` (`Attach` / `KeepAlive` / `Reconcile` /
> `SetKillSwitchPolicy` / `StartHeartbeat` / `Close`) is implemented over
> stdlib `net/http` with pre-encoded protobuf payloads so `go build` works
> before `buf generate`. Typed wrappers over `gen/` (produced by `buf`) are
> the next step; Python/TypeScript remain the richest clients today.

Tier-2 thin wrapper over the generated longtrader Connect stubs. Hand-written
code stays minimal — session handling plus overflow policies — while all
trading semantics live in the contract (`proto/`, buf-managed).

## Installation

```bash
go get github.com/longcipher/longtrader/sdks/go
```

The module is served from the repository via pkg.go.dev — no separate registry
account is required. Regenerate the stubs with `just sdk-generate` only when
working from source.

**Requirements:** Go >= 1.23.

## Canonical layout (design doc §6.8)

| Canonical dir | This SDK |
|---|---|
| `contract/` | `gen/` — generated by `buf generate` (`paths=source_relative`), never hand-edited |
| `session/` | `session/` — `Session` lifecycle over stdlib http (gen-free byte API) |
| `ports/` | `ports/` — `TradingPort`, `MarketPort`, `OverflowPolicy` (byte API) |
| `adapters/` | thin by design: Connect-over-http inside `session/`; mock adapter planned |
| `strategies/` | `strategies/` — the same grid is planned, not yet shipped |
| `examples/` | `examples/` — placeholder for now |

Concept names are intended to match the Python/TypeScript/Rust wrappers 1:1
(`Session`, `TradingPort`, `MarketPort`, `sync_state()`, `OverflowPolicy`).

## Quickstart (byte API — works without `gen/`)

```go
s, raw, _ := session.Attach("http://127.0.0.1:8080", "YOUR_TERMINAL_TOKEN", attachReqBytes)
// decode raw AttachSessionResponse with ../gen types, then:
s.SetAttached(sessionID, heartbeatMs)
s.StartHeartbeat(time.Duration(heartbeatMs)*time.Millisecond, keepAliveFn, onExpired)
snapRaw, _ := s.Reconcile(token, reconcileReqBytes) // gate to ACTIVE
fmt.Println(s.SessionID, s.State())
s.Close()
```

## Wire notes (accurate today)

- Unary calls: `POST {base}/longtrader.worker.v1.WorkerSessionService/{Method}`,
  `Content-Type: application/proto`; errors arrive as non-200 JSON bodies
  surfaced as `ConnectError`.
- Server-streaming uses `application/connect+proto` with 5-byte envelopes
  (1 flag byte + u32 big-endian length; flag `0x02` = end-of-stream JSON).
  See `../docs/bare-protocol-guide.md` sections 4–5 and `envelope` helpers in Rust.
- Auth is the existing terminal API token passed to `AttachSession`.
- `OverflowPolicy` governs event-queue behavior under slow consumers
  (`DropOldest` preserves newest, `Coalesce` last-writer-wins, `Block`
  applies backpressure); sequence gaps require snapshot resync/reconcile.

## Local regeneration

Requires `buf` CLI. From repo root:

```bash
buf generate --template proto/buf.gen.yaml
# or
just sdk-generate    # cd proto && buf generate
```

> **Note:** `scripts/gen-proto.sh` generates Python, TypeScript, and Go
> (Go via `buf generate --template buf.gen.yaml`; skipped when `buf` is missing).

`proto/buf.gen.yaml` contains the Go plugin entry:

```yaml
- remote: buf.build/protocolbuffers/go:v1.36.10
  out: ../sdks/go/gen
  opt:
    - paths=source_relative
```

Output is `sdks/go/gen` (quarantined contract, never hand-edited).
